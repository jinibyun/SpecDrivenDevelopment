# BookFlow — UI Spec (ui.md)

> `spec.md` §7 (UI Structure)에서 분화된 문서. 다음 단계(Claude Design)에서 이 문서를 기반으로 실제 화면을 생성합니다.

## 1. Visual Tone

- **고객용 페이지**: 화이트 톤 기반 미니멀 예약 폼. 여백 넉넉하게, 단계별 진행(서비스 선택 → 슬롯 선택 → 정보 입력)이 한눈에 보이는 구조
- **관리자 대시보드**: 다크 사이드바 + 화이트 콘텐츠 영역의 SaaS 스타일
- **Accent color**: 신규 브랜드 톤 — 기존 프로젝트(Kibo, K-Medispa 등)와 구분되는 포인트 컬러 사용 (예: 블루 계열, 확정 시 반영)
- **Typography**: 깔끔한 산세리프, 한글은 Pretendard 또는 시스템 폰트

## 2. Routes & Pages

### 2.1 `/` — 고객용 예약 페이지 (Public)

**구성 요소**
- Header: 로고 + 서비스명
- Step 1 — 서비스 선택 카드 목록 (services 목록, 이름/소요시간/가격)
- Step 2 — 날짜 선택 (캘린더) + 가능 시간 슬롯 버튼 그룹
- Step 3 — 예약자 정보 입력 폼 (이름/연락처/이메일 선택/요청사항)
- Step 4 — 제출 버튼 → 성공 시 확인 화면 (예약 요약 + "확인 메시지가 발송되었습니다")

**상태**: 슬롯 로딩 중 skeleton. `GET /api/bookings/availability`가 예약 가능한 슬롯만 반환하므로, 마감된 시간은 목록에서 아예 제외된다 (비활성화 표시 대신 미노출).

### 2.2 `/admin/login` — 관리자 로그인

- 이메일/비밀번호 입력 폼
- 심플한 단일 카드 레이아웃, 중앙 정렬
- 인증은 Neon Managed Auth(`authClient.signIn.email`)로 처리. 인증되지 않은 상태로 `/admin/dashboard`·`/admin/customers`에 직접 접근하면 `proxy.ts`가 이 페이지로 리다이렉트한다.

### 2.3 `/admin/dashboard` — 예약 현황 대시보드

**레이아웃**: 좌측 다크 사이드바(대시보드/예약/고객/설정) + 우측 콘텐츠. 사이드바는 `/admin/dashboard`·`/admin/customers`가 공유하는 `(shell)/layout.tsx`에 있고, 하단 프로필 영역에 로그인한 관리자 이메일과 "로그아웃" 버튼(`authClient.signOut()` → `/admin/login`)이 있다.

**콘텐츠 구성**
- 상단 요약 카드 3~4개: 오늘 예약 수, 대기중, 이번주 노쇼율, 총 고객수
- 예약 목록 테이블: 고객명 / 서비스 / 일시 / 상태(뱃지) / 액션(승인·취소 버튼)
- 상태 필터 탭: 전체 / 대기 / 확정 / 완료 / 노쇼

### 2.4 `/admin/customers` — 고객 관리

- 고객 목록 테이블: 이름 / 연락처 / 총 예약수 / 노쇼 횟수
- 검색창 (이름/연락처 기준)
- 행 클릭 시 해당 고객의 예약 이력 상세 보기 (모달 또는 서브페이지)

## 3. Shared Components (ShadCN 기반)

- `Button`, `Card`, `Badge` (예약 상태 표시), `Table`, `Calendar`, `Dialog`, `Input`, `Select`

## 4. Component → Data Mapping

| Component | Data Source |
|---|---|
| 서비스 선택 카드 | `GET /api/services` |
| 슬롯 선택 버튼 그룹 | `GET /api/bookings/availability` |
| 예약 목록 테이블 (admin) | `GET /api/admin/bookings` |
| 상태 뱃지 액션 | `PATCH /api/admin/bookings/:id` |
| 고객 목록 테이블 | `GET /api/admin/customers` |
| 로그아웃 버튼 (사이드바) | Neon Managed Auth `authClient.signOut()` (`/api/auth/*`) |

## 5. Claude Design 생성 시 프롬프트 가이드 (라이브 데모용)

1차: "`/` 고객용 예약 페이지를 위 UI 스펙대로 생성" → 2차: "`/admin/dashboard` 관리자 대시보드를 위 스펙대로 생성" 순으로 두 화면을 순차 생성하여 시연.
